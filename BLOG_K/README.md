# Blog personal - Omar Lozano

PHP simple para Vercel. Todo va en un solo `index.php` (foto y estilos incluidos).

## Archivos para GitHub

```text
BLOG_K/
├── index.php
└── vercel.json
```

## Subir

1. En GitHub abre `index.php` → Edit → pega el contenido nuevo → Commit
2. En GitHub abre `vercel.json` → Edit → pega el contenido nuevo → Commit
3. En Vercel → Redeploy

## Ver en PC

```bash
php -S localhost:8000
```
